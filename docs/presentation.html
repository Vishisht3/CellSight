The Problem — Two Disconnected Worlds

Industrial EV fleets and battery supply chains operate in silos, with no shared intelligence layer
2 / 13
⚠ The Problem
🚛 Fleet Operators — No Battery APM

Industrial machinery has decades of Asset Performance Management tooling. EV batteries have none. Fleet managers are blind to degradation rates, thermal risk, and replacement timing — leading to unplanned downtime and accelerated degradation from suboptimal charging patterns.

🏭 EV Manufacturers — Supply Chain Opacity

Critical battery materials traverse 3+ supplier tiers with no unified risk view. Concentration, geopolitical, quality, and compliance risks are completely siloed. When field packs degrade faster than expected, there is no mechanism to trace back to the originating cell batch or raw material supplier.

🔗 The Gap Nobody Fills

Field performance data sits with fleet operators. Supply chain data sits with manufacturers. The correlation that would improve both sides — linking real-world degradation to the batch and supplier that caused it — is never made.

✓ CellSight — One Platform, Two Agents, One Shared Thread
APM Agent → Fleet Operators
  • State-of-Health via OLS regression on 7 telemetry features
  • Remaining Useful Life linear extrapolation from SoH history
  • Thermal event detection within the last 10 readings
  • Charge pattern optimisation (20–80% SoC window)
  • Ranked predictive maintenance trigger queue
Supply Chain Agent → Manufacturers
  • 3-tier material traceability (lot → batch → pack → asset)
  • 4-dimension supplier risk scoring: concentration, geopolitical, quality, compliance
  • Full chain query in <3 seconds
🔗 Correlation Agent — The Differentiator

Uses z-score statistical outlier detection (z > 2.0) to flag cell batches and suppliers whose assets degrade significantly faster than the fleet population — creating a closed feedback loop visible to both fleet managers and supply chain managers simultaneously.

AI/ML Architecture — Built From Scratch, No External ML Libraries

Three AI agents, five algorithms, all implemented in pure TypeScript — deployed to Railway with PostgreSQL

🤖 APM Agent
SoH Calculation Service
OLS Linear Regression Feature vector (7-dim):
[1, cycles, avgV, avgTemp, avgSoC, σV, σT]
Normal equation:
β = (XᵀX)⁻¹ Xᵀy
Matrix inversion: Gauss-Jordan
80/20 train/test split, RMSE logged
Fallback: physics rule-based formula
RUL Linear Extrapolation RUL = (SoH − 80%) ÷ deg/day
From SoH history slope.
Confidence scales with data volume.
⬇ Runs every 5 min on all assets
🤖 Supply Chain Agent
Risk Scoring Service
4-Dimension Risk Formula Concentration: share ÷ 0.35
Geopolitical: binary ∈ {CN,RU,VE}
Quality: out-of-spec lots ÷ total lots
Compliance: 1 − days/90 ramp
Each dimension: 0–1 score
Composite risk score: 0–100
Traceability Service 4-tier chain traversal:
Asset → Pack → Batch → Mfr → Lots
Resolved in <3 s per asset.
⬇ Runs every 5 min on all suppliers
🤖 Correlation Agent
Field-to-Source Correlation
Z-Score Outlier Detection For each supplier/batch:
Avg degradation rate of linked assets
z = (rate − μ) / σ
Flag if z > 2.0 (95th percentile)
Self-calibrates as fleet grows.
Min confidence 0.5 required.
Predictive Maintenance Checks Thermal: last 10 readings vs ±10°C
SoH: vs 85%/80% thresholds
Charge: avg SoC min/max pattern
⬇ On-demand + scheduled batch
