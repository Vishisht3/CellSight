The Problem  India's industrial EV gap
  • India registered 2M+ EVs in FY2025 — yet industrial segments (freight, mining, logistics) remain below 2.5% penetration. SIAM FY2025
  • FAME-II has disbursed ₹10,000+ crore. The barrier to 30% EV penetration by 2030 is not financial — it's operational. Fleet operators lack the tools to manage EV battery lifecycle with industrial rigour.
  • Manufacturers have no supply chain visibility. When packs degrade faster than expected, there is no mechanism to trace back to the originating cell batch or raw material supplier.
  • The correlation nobody makes: field performance data sits with fleet ops; supply chain data sits with manufacturers. CellSight connects the two automatically.

How the AI Works  OLS regression + z-score statistics — no black-box ML
State of Health — OLS Regression
// Feature vector (7 dimensions) β = (XᵀX)⁻¹ Xᵀy // normal equation // Gauss-Jordan inversion, 80/20 train/test // Features: cycles, avgV, avgTemp, avgSoC, // voltStdDev, tempStdDev, bias RUL = (SoH − 80%) ÷ degradation/day
~150 lines of pure TypeScript. No external ML libraries — fully inspectable, no native binary deps, small Docker image.
Field-to-Source Correlation — Z-Score
// Self-calibrating outlier detection z = (supplierAvgDegRate − μ) / σ // z > 2.0 ≈ 95th percentile → alert fires // Threshold auto-adjusts as fleet grows
SPC (QMS) uses the same z-score approach for process parameters. Consistent statistical method across all intelligence modules.
