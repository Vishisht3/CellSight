Market Context

The Industrial EV Transition Has a Critical Intelligence Gap

Two Disconnected Worlds

Fleet Operators — No Battery APM Tooling

Industrial machinery has decades of Asset Performance Management tooling. EV batteries have none. Fleet managers have no visibility into real-time degradation rates, thermal risk, or optimal replacement timing — resulting in unplanned downtime and accelerated battery wear from suboptimal charging.

EV Manufacturers — Supply Chain Opacity

Battery materials traverse 3+ supplier tiers with no unified risk view. Concentration, geopolitical, quality, and compliance risks remain siloed. When field packs degrade ahead of schedule, there is no mechanism to trace the failure back to the originating cell batch or raw material supplier.

The Gap Nobody Fills

Field performance data sits with fleet operators. Supply chain data sits with manufacturers. The correlation that would improve both sides — linking real-world battery degradation to the specific cell batch and material supplier that caused it — is never made.

Artificial Intelligence

State-of-Health Model — OLS Regression Implemented From Scratch

No external ML libraries · 7-feature vector · Gauss-Jordan normal equations · 80/20 train/test split with RMSE validation · Physics-based fallback

Model Architecture

// Feature vector (per 100-point telemetry window) x = [1, totalCycles, avgVoltage, avgTemp, avgSoC, voltStdDev, tempStdDev] // Normal equation — Gauss-Jordan inversion β = (XᵀX)⁻¹ Xᵀy // Fallback physics formula SoH = 100 − (cycles × 0.05) − voltageFade − tempStress

The model trains on startup across all assets, using the physics formula as the ground-truth label for sliding 100-point windows. An 80/20 train/test split is applied and RMSE is logged. If fewer than 10 samples are available or the matrix is singular, the physics fallback activates automatically.

RUL Prediction

RUL(days) = (currentSoH − 80%) ÷ degradationRate/day confidence = min(1.0, readings / 200)

Degradation rate is derived from the slope of the SoH history record set. Confidence scales linearly with telemetry volume, reaching maximum at 200 readings (typically 2–5 days of operation).

// Z-score per supplier z = (avgDegRate − μ) ÷ σ // μ and σ computed across all suppliers // with confidence ≥ 0.5 (≥ 5 linked assets) // Flag if z > 2.0 (≈ 95th percentile) // Self-calibrates as fleet grows

Why Z-Score, Not a Fixed Threshold?

A fixed 20% deviation threshold treats the same deviation identically whether a supplier has 3 or 300 linked assets. Z-score is self-calibrating — the significance level adjusts automatically as the fleet and supplier base grow, eliminating the need for manual threshold tuning.

The Core Differentiator

This is the only platform that automatically links real-world field degradation back to the originating supplier batch. When this alert fires, it is delivered simultaneously to the fleet manager and the supply chain manager — creating a shared feedback loop between two teams that previously had no connection.

Outbox Pattern — Guaranteed Delivery

1

AlertService writes the alert record and an outbox_events row in a single atomic transaction. Dual-write inconsistency is architecturally impossible.

2

OutboxPublisher polls unpublished rows every second and pushes events to all connected SSE clients.

3

On reconnect, the browser sends a Last-Event-ID header. The server replays all missed events since that ID — no alert is ever lost during a network interruption.

Charge Impact Flag

Jobs that require an EV charging slot in addition to a workshop bay are explicitly flagged. The Day Shift is fully booked — the Forklift-FL05 battery replacement must therefore be allocated to the Afternoon Shift, which has 5 free charge slots. This prevents scheduling conflicts without manual cross-referencing.

Production Engineering Note: Deferred Scheduler Start

The scheduler's first tick is deliberately deferred by one full interval (5 minutes). This ensures the platform's Railway health check responds before any blocking database work begins — preventing the service from being marked unhealthy during cold start. This is a real production consideration, not a demo accommodation.
