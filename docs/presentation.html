The Problem & What CellSight Solves

1.1   Industrial EV fleets have no Asset Performance Management tooling for their batteries. Fleet managers cannot see degradation rates, thermal risk, or replacement timing — leading to unplanned downtime and accelerated wear from suboptimal charging.

🚛 Fleet Operators — No Battery APM

EV batteries have no equivalent of the APM tools industrial machinery has enjoyed for decades. Managers are flying blind on degradation, thermal risk, and replacement timing.

🏭 EV Manufacturers — Supply Chain Opacity

Battery materials traverse 3+ supplier tiers with no unified risk view. When field packs degrade faster than expected, there is no way to trace back to the originating cell batch.

1.2   CellSight bridges this gap with three AI agents on a shared platform — an APM Agent for fleet operators, a Supply Chain Agent for manufacturers, and a Correlation Agent that statistically links field degradation back to the batch and supplier that caused it.

🤖 APM Agent

OLS regression SoH · RUL prediction · Thermal detection · Charge pattern analysis · Predictive maintenance queue

🤖 Supply Chain Agent

4-dimension risk scoring · 3-tier material traceability · Certification compliance · Full chain in <3 s

🔗 Correlation Agent

Z-score outlier detection (z > 2.0) · Links batch degradation to suppliers · Cross-role alert visibility

How the AI Works — OLS Regression & RUL Prediction

5.1   The State of Health value shown on every asset is computed by a bespoke Ordinary Least Squares linear regression model — implemented entirely in TypeScript, no external ML libraries.

OLS Regression — SoH Calculation Service
Input Features (7-dimensional)
1 (bias term)
totalCycles
avgVoltage
avgTemperature
avgStateOfCharge
voltageStdDev
tempStdDev
Training Process
Normal equation: β = (XᵀX)⁻¹ Xᵀy
Matrix inversion via Gauss-Jordan
Sliding 100-point windows, 50-point stride
80 / 20 train / test split
RMSE computed on held-out set, logged at startup
Fallback: physics formula if <10 training samples
Physics fallback:  SoH = 100 − (cycles × 0.05) − voltageFade − tempStress
where voltageFade = max(0, (400V − avgV) / 400) × 10   and   tempStress = max(0, (avgTemp − 35°C) × 0.2)

5.2   Remaining Useful Life (RUL) is predicted by linear extrapolation from the SoH history slope:

RUL (days) = (currentSoH − 80%) ÷ degradationRatePerDay
Degradation rate = (oldest SoH − newest SoH) ÷ elapsed days from SoH history records. Confidence linearly scales 0 → 1 as data accumulates toward 200 telemetry points.

5.3   The Predictive Maintenance engine runs four automated checks per asset every 5 minutes:

CheckAlgorithmAlert triggered when
Thermal EventLast 10 telemetry readings vs limitsTemp < −10°C or > 45°C
SoH DegradationcurrentSoH vs configured thresholds< 85% → WARNING  |  < 80% → CRITICAL
RUL ThresholdLinear RUL extrapolation from history≤ 30 days → WARNING  |  ≤ 7 days → CRITICAL
Charge PatternLast 100 SoC readings — avg min/maxAvg SoC min < 20% or max > 80%
Why no external ML library? The entire pipeline — feature extraction, matrix multiplication (XᵀX), Gauss-Jordan inversion, train/test split, RMSE evaluation — is ~150 lines of pure TypeScript. This avoids native binary dependencies, keeps the Railway Docker image small, and makes the model fully inspectable and testable without a Python environment.

Field-to-Source Correlation — Z-Score Outlier Detection

8.1   Navigate to Correlation and click "Run Analysis". The agent computes each supplier's average battery degradation rate across all linked assets, then applies z-score statistics to identify statistical outliers.

CobaltMines Ltd0.0487%0.038%+28.3%z = 2.84 ⚡

▲ Red bars are statistical outliers (z > 2.0). Their assets are degrading significantly faster than the fleet population — not just faster in absolute terms, but faster than expected given normal variation.

▲ The Z-Score column shows the exact significance. CobaltMines z = 2.84 means its assets degrade faster than 99.8% of the fleet population — a highly significant signal.

8.2   Formula:  z = (supplierAvgDegRate − μ) / σ   where μ and σ are computed across all suppliers with confidence ≥ 0.5. Any z > 2.0 triggers a FIELD_TO_SOURCE_CORRELATION alert visible to both fleet and supply chain managers.

Why z-score instead of a fixed 20% threshold? A fixed threshold treats a 21% deviation the same whether the fleet has 3 assets or 300 linked to that supplier. Z-score is self-calibrating — as the fleet grows the threshold adjusts automatically with the population distribution. No manual tuning required.

Outbox Pattern — how alerts reach the browser in real time:
Step 1. AlertService writes the alert and an outbox_events row in a single atomic database transaction — no dual-write inconsistency possible.
Step 2. OutboxPublisher polls unpublished outbox rows every second and pushes them to SSE clients.
Step 3. On reconnect the browser sends a Last-Event-ID header. The server replays all missed events since that ID — no alert is ever lost during a network drop.

SPA head management: Since CellSight has no server-side rendering, all <head> metadata is managed client-side. The hook uses document.querySelector to locate existing tags before creating new ones — no duplicates accumulate across route changes.

Why disallow authenticated routes? Search engines should not index pages that require login — those pages would return a redirect to /login for crawlers. Disallowing them prevents wasted crawl budget and avoids confusing search results.
