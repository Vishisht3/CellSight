The Problem India's industrial EV gap
  • India registered 2M+ EVs in FY2025 — yet industrial segments (freight, mining, logistics) remain below 2.5% penetration. SIAM FY2025
  • FAME-II has disbursed Rs 10,000+ crore. The barrier to 30% penetration by 2030 is not financial — it is operational. Fleet operators lack tools to manage EV battery lifecycle with industrial rigour.
  • Manufacturers have no supply chain visibility. When packs degrade faster than expected, there is no mechanism to trace back to the originating cell batch or supplier.
  • The correlation nobody makes: field performance data sits with fleet ops; supply chain data sits with manufacturers. CellSight connects the two automatically.

How the AI Works OLS regression + z-score statistics -- no black-box ML
State of Health -- OLS Regression
// Feature vector (7 dimensions) beta = (X'X)^-1 X'y // normal equation // Gauss-Jordan inversion // 80/20 train/test split + RMSE // Features: cycles, avgV, avgTemp, // avgSoC, voltStdDev, tempStdDev, bias RUL = (SoH - 80%) / degradation_per_day
~150 lines of pure TypeScript. No external ML libraries -- fully inspectable, no native binary deps.
Field-to-Source Correlation -- Z-Score
// Self-calibrating outlier detection z = (supplierAvgDegRate - mu) / sigma // z > 2.0 = 95th percentile // → FIELD_TO_SOURCE alert fires // → both fleet + supply chain see it // threshold auto-adjusts as fleet grows
Same z-score method used in QMS SPC monitoring -- consistent statistics across all modules.
